# AllStar Optik

Bağımsız, kişisel kullanım amaçlı Android optik kontrol projesi. 345 Yayınevi'nin resmî uygulaması değildir.

## Tasarlanan akış
QR tara veya test ara → A-E optik işaretle → doğru / yanlış / boş / net → yerel istatistikler → yanlış sorunun fotoğrafından adım adım yapay zekâ çözümü.

## Kaynak dosyalarının yüklenmesi
Bu depo şu anda GitHub'da **Public** görünüyor. Kullanıcı tarafından sağlanan cevap anahtarları ve bunlardan çıkarılan SQLite veritabanı, kişisel kullanım amacıyla verilmiş olduğundan **depo Private yapılana kadar yüklenmeyecektir**.

Depo özel yapıldıktan sonra Android projesi ve APK derleme iş akışı buraya aktarılacak. Cevap anahtarlarındaki otomatik çıkarım hataları ayrıca doğrulama gerektirir.
